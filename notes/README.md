# Node.js Backend Manual

My notes from **Node.js, Express, MongoDB & More: The Complete Bootcamp** (Jonas Schmedtmann, Udemy), written while building [workout-log-api](../README.md).

> **How to use it:** every section ends with a **Test yourself** block. Answer from memory *before* expanding it. If you can't, re-read that section, not the whole course.

The course is plain JavaScript with CommonJS and Express 4. My project uses TypeScript, ES modules and Express 5, so each part has a **Course vs my project** box with the differences.
